# S1RA (Sterōid 1) — Parody Website

A parody pharmaceutical website that mimics GLP-1 drug advertising (Ozempic, Mounjaro) but instead of weight loss, it promotes steroids and weight/muscle gain.

## Concept

| Real | Parody |
|------|--------|
| Ozempic / Wegovy (semaglutide) | S1RA (Sterōid 1) |
| Weight loss | Weight / muscle gain |
| Appetite suppression | Uncontrollable hunger |
| "Stop the cycle of overeating" | "Stop losing. Start growing." |
| GLP-1 receptor agonist | "Androgen receptor modulator" |
| Savings card / find a provider | Same UI, but absurd |
